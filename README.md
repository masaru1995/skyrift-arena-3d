# SKYRIFT ARENA 3D

スマホのブラウザーで遊べる、オリジナルの3D吹っ飛ばし対戦ゲームです。
公開ページは GitHub Pages で配信するため、作成に使用したPCを起動する必要はありません。

## プレイ

公開URLを Safari または Chrome で開き、キャラクターとステージを選んで「対戦スタート」。横向き推奨ですが、縦向きにも対応しています。1人対CPU専用です。

- 左のスティック：画面の向きに合わせて360度移動。
- 跳ぶ：ジャンプ。空中でもう一度押すと二段ジャンプ。
- 攻撃：押して離すと攻撃。長押しで溜め攻撃。近くの敵に自動照準。
- 必殺：地上では固有技。空中では上昇して復帰。着地まで1回。
- 守る：地上で長押しするとシールド。使い続けるとゲージを消費。

NOVA は星弾、EMBER は回転攻撃、MOSS は周囲への衝撃波。空中復帰はスティック方向へ、入力がなければアリーナ中央へ向かいます。

通常対戦は3ストック・2分。時間切れは残りストック、次にダメージの少なさで判定。練習モードは無制限で、CPUは攻撃しません。通常対戦の途中でメニューへ戻った場合は戦績に記録しません。

PC操作：WASDまたは矢印キーで移動、SPACEでジャンプ、Jで攻撃、Kで必殺、Lまたは左SHIFTでシールド、Esc/Pで一時停止。

## ホーム画面・オフライン

ホーム画面に追加すると、対応ブラウザーではアプリ風に起動できます。初回はインターネット接続が必要です。サービスワーカーによる保存が完了した後は、対応ブラウザーでオフライン再起動も可能です。保存状態やブラウザーの容量整理によって、再接続が必要になることがあります。

描画が重い場合は、メニュー右上の設定から品質を「軽量」にしてください。WebGLが無効なブラウザーや一部のアプリ内ブラウザーでは動作しない場合があります。スマホ実機での動作・フレームレートは未検証です。

## ファイル

`index.html` / `style.css` / `engine.js` / `game.js` がゲーム本体です。独自のWebGL 1レンダラーを使用し、ゲーム実行時の外部ライブラリー・外部画像・外部フォントはありません。モデル、背景、効果音はコードで生成します。

Webサーバーからこのディレクトリーをそのまま配信できます。別添の単体HTML版はCSS・JavaScriptを1ファイルにまとめた保存用です。スマホではローカルHTMLを実行しないファイルプレビューがあるため、プレイには公開URLを使用してください。

戦績と音・画質設定はこの端末のlocalStorageに保存します。ゲームにログイン、広告、アクセス解析、独自の個人情報送信処理はありません。配信サービスの標準的なアクセスログは本ゲームの制御外です。

テスト用操作APIは、localhostか127.0.0.1で `?test` を付けた場合だけ有効です。公開サイトでは有効になりません。
